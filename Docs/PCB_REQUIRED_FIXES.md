# PCB量产前必须修复与验证清单

> 本文件保留中文，作为当前 `STM32G0B1CBT6N / PCB2` 版本的量产放行清单。更新基线：2026-08-16。P4已确认用于切断外部220V市电，不再按低压接口处理。

## 1. 当前结论

当前低压测量与控制链路已经形成可打样、可联调的工程版本：

- U5已改为STM32G0B1CBT6N；
- 热电偶输入采用MAX6675、低漏电ESD、47Ω串联电阻和100nF滤波；
- 已确认只使用绝缘型/非接地结K型热电偶；
- 0–5V输出采用2.5V VREFBUF、PA4 DAC、TLV9351和P2端ADC回读；
- 已有DAC默认100kΩ下拉和P2端ESD；
- USB、SWD、手动BOOT/RESET、24V/USB双路供电完整；
- 已新增THVD1400DR非隔离半双工RS-485、SM712保护和P5端子；
- PCB顶层和底层均有GND覆铜；
- 继电器区域有3个多层`NO_POURS`区域；
- EasyEDA严格DRC在当前规则下为0项错误。

但是，**整板目前不能直接用于220V量产**。主要阻断项不是普通DRC，而是继电器触点与低压线圈侧的物理隔离距离及缺少市电到SELV的专用规则。

## 3. P0：量产前必须修复

### P0-1：重做220V继电器隔离路径

当前实测/规则状态：

- 市电走线到继电器24V线圈侧最近约**3.10mm**；
- 市电走线到P2区域GND最近约**3.28mm**；
- 继电器触点焊盘到线圈焊盘最近边缘距离约为**3.53mm**；
- 市电铜到模拟反馈区域最近约**4.77–4.94mm**；
- 当前项目保守放行目标为市电铜到所有SELV铜至少**8mm电气间隙和爬电距离**，最终数值仍需由整机标准、过电压类别、污染等级、材料组、海拔和绝缘等级确定；
- 现有3个区域只有`NO_POURS`，只能阻止覆铜，不能阻止走线、Via、焊盘和手工填充；
- `RELAY_CONTACT`规则中，覆铜到其他对象约4.0mm，但多数走线/焊盘/Via之间仍约0.18mm；
- `$1N128`、`$1N129`没有配置市电到SELV的8mm网络对网络规则；
- 触点网络当前爬电规则仍为默认0mm；已有`CREEP_24V=0.3mm`也没有分配给市电网络；
- 因此当前DRC为0并不能证明220V隔离合格。

必须完成：

1. 更换或重做继电器及封装，使线圈—触点本体和PCB焊盘间距满足最终隔离要求；
2. 优先评估明确声明线圈—触点8mm间隙/8mm爬电的继电器系列，例如合适规格的Omron G2RL；最终型号必须按24V线圈、负载电流、浪涌、触点寿命、温度和认证选择；
3. 在顶层和底层建立完整的市电隔离走廊，同时禁止覆铜、走线、Via和填充进入；
4. 把继电器未使用触点焊盘也纳入危险市电区域；
5. 为`$1N128`、`$1N129`到全部SELV网络建立专用网络间距规则；
6. 检查到板边、安装孔、USB、SWD、P1、P2、P3、MCU、24V及所有GND铜的距离；
7. 重新覆铜、严格DRC，并单独做一次市电隔离人工审查。

注意：开槽只能增加爬电距离，不能增加现有继电器焊盘之间的空气间隙。仅扩大覆铜禁布区不能解决3.53mm的物理间距问题。

### P0-2：确认P4、继电器和外部保护等级

P4使用WJ2EDGV-5.08-02P-14-00A，EasyEDA库数据显示5.08mm间距、10A、300V。RLY1当前为SRD-24VDC-SL-C。库属性不是认证证据，量产前必须取得并锁定实际制造商数据手册。

必须确定：

- 220VAC具体接线位置，是火线还是其他回路；
- 连续电流、启动浪涌、负载类别和功率因数；
- 外部保险丝/断路器规格和位置；
- 继电器触点降额、机械/电气寿命和失效模式；
- 接线端子、线材、压接、外壳和防触电等级；
- 适用整机安全标准和耐压测试条件。

P4建议丝印为`NC (L)`和`COM (L)`，并增加高压警告。生产测试时不得让普通低压治具在市电带电时接触P4。

### P0-3：补齐STM32G0B1CBT6N的VDDIO2去耦

最新N版本引脚：

- pin30：VSS，接GND；
- pin31：VDDIO2，接`3V3_SYSTEM`；
- C24：100nF，接在VDDIO2与VSS之间。

ST供电建议还显示该供电对需要本地4.7µF。量产前在pin31/pin30附近增加4.7µF，并保持C24 100nF贴近引脚。不得在VDD无效时单独给VDDIO2上电。

### P0-4：整机必须有独立超温保护

软件PID、MAX6675、MCU、DAC、ADC和当前继电器属于同一控制系统，不能作为唯一安全保护。整机至少需要一种不依赖本板软件和供电的独立保护，例如：

- 机械温控开关；
- 一次性温度保险丝；
- 独立温控器；
- 安全继电器/接触器；
- 或符合整机风险等级的等效保护。

必须验证MCU跑飞、固件升级、热电偶脱落、本板断电和24V丢失时，独立保护仍能切断危险加热。

### P0-5：确认常闭继电器的故障语义

- PB0低或本板断电：线圈释放，P4 NC-COM闭合，220V路径导通；
- PB0高且24V存在：线圈吸合，P4 NC-COM断开。

因此，本板掉电时不会自动切断220V。固件进入故障、DFU或复位前应先将DAC置0V；若24V仍存在，再按整机策略令PB0为高以打开P4。这个动作不能替代独立硬件保护。

### P0-6：完成热电偶可信度验证

只允许绝缘型/非接地结K型热电偶。每批探头或合格抽检必须确认：

- K+、K-极性；
- 探头结与金属外壳/机器地之间绝缘；
- 开路检测；
- 室温、中温、高温对比；
- 200–600°C范围内的稳定性和重复性；
- 热风机、继电器、USB和24V转换器工作时的噪声/跳变；
- 长线、接插件和屏蔽接地方式。

固件建议250ms采样，并检测开路、陈旧数据、异常跳变、粘滞数据和不合理升温速率。不得用平均滤波掩盖故障。

### P0-7：完成0–5V校准和真实负载验证

```text
运放增益 = 1 + 10.5k/10k = 2.05
DAC理论满量程 = 2.5V
模拟理论满量程 = 5.125V
5.000V对应DAC码约3995/4095
ADC分压 = 51k/(56k+51k) = 0.4766355
P2=5.000V时，PA0约2.383V
```

必须在真实热风机控制输入下测量：

- 0V、0.5V、2.5V、4.5V、5.0V；
- R11前后压差和外部输入阻抗；
- PA0 ADC回读及命令/回读误差；
- 输出噪声、温漂、稳定时间和短路行为；
- USB供电、24V供电及两者同时存在时的行为。

固件应保存带CRC的输出偏移、斜率和版本信息，限制0–5V，检测卡高、卡低和持续偏差。ADC回读不能作为独立安全保护。

### P0-8：确认24V供电边界

U2 K7805-500R3输入上限为32V。保留条件是机器24V已经确认稳定，但仍必须用示波器记录：

- 开机和关机；
- 继电器吸合/释放；
- 加热控制阶跃；
- USB插拔和双电源切换；
- RS-485长线、分支、端接、共模扰动、ESD/EFT和通信中断；
- 最坏线缆和负载条件。

D8 SMAJ24A用于瞬态钳位，但本设计不声明汽车抛负载或高能浪涌能力。如果实测接近30V，必须换成45–60V输入额定的24V转5V器件并重新验证保护链路。

### P0-9：锁定RS-485拓扑、端接和公共地条件

当前RS-485基线：

- U6：THVD1400DR，3.3V供电；
- PA1：RS485_DE，PA2：RS485_TX，PA3：RS485_RX；
- /RE与DE并联，R21 10kΩ下拉，复位默认接收；
- R19/R20：A、B各10Ω串联；
- D4：SM712；P5：1脚B、2脚A；
- R22：A/B之间120Ω；
- 接口非隔离，P5没有独立GND脚，依赖机器内已经确认的公共地。

R22必须改成明确的装配选项、DNP、焊桥或跳帽。只有当本板是整条RS-485总线两个电气终端之一时才装120Ω。板子位于被动分支末端，不代表它一定应端接；被动星形网络每个分支都装120Ω会使等效负载过低并恶化通信。

量产前必须记录：

1. 真实拓扑、主干和分支长度；
2. 哪两个位置装端接；
3. 线缆类型、波特率、最大节点数和最大长度；
4. 双方公共地连接及最坏共模电压；
5. 误码率、掉线恢复、ESD/EFT和接地扰动结果；
6. 通信失联不得解除本地温控和故障保护。

### P0-10：完成ESD回流、去耦、孤立网络和丝印清理

最新PCB检查还需要完成：

- D3热电偶ESD到最近GND Via约9.34mm；在D3 GND脚旁增加小于1mm的泄放Via；
- D2 USB ESD到最近GND Via约2.75mm；增加就近GND Via；
- D4 RS-485保护到最近GND Via约2.58mm；增加就近GND Via；
- D4到P5的保护路径约8–13.5mm，尽量缩短到3–5mm；
- C15 100nF移到U3供电脚与GND旁，C20 1µF随后放置；
- C25 100nF移到U6 VCC/GND旁，C26 1µF随后放置；
- 删除没有连接焊盘的两个旧3V3_SYSTEM孤立走线段；
- 在顶层补齐P1–P5和H1的接口丝印，不能只依赖底层丝印；
- P5顶层丝印必须直接标出B和A，P4必须带高压警告。

## 5. BOM和生产资料

批量采购前，每个物料必须锁定：

- 制造商和制造商料号；
- 嘉立创/LCSC编号；
- 封装和高度；
- 阻值/容值、精度和温漂；
- 功率、耐压和电容介质；
- 工作温度；
- 是否允许替代及替代验证方法。

禁止只按原理图显示值采购。特别复核VREFBUF、VDDIO2、U3 24V去耦、TVS、保险丝、继电器、P4端子和所有高压相关物料。

## 6. 首板测试顺序

### 6.1 低压测试

1. 断电检查短路、极性和装配方向；
2. USB限流供电，检查`5V_SYSTEM`、`3V3_SYSTEM`和VDDIO2；
3. SWD识别、擦除、烧录、复位和调试；
4. 固件启用VREFBUF后检查VREF+=2.5V；
5. USB CDC枚举；
6. MAX6675已知温度和开路测试；
7. 24V限流上电，检查`24V_PROTECTED`和`5V_FROM_24`；
8. 0–5V全量程、真实负载和ADC回读；
9. 用安全低压测试PB0高时P4 NC-COM断开；
10. 手动DFU、软件DFU和SWD救砖；
11. RS-485收发、方向切换、端接、误码率和掉线恢复测试。

### 6.2 市电测试

只有完成P0-1、P0-2且高压设计审查通过后，才允许在隔离、带联锁和防触电的治具中连接220VAC。必须验证：

- 空载和真实负载开断；
- 最大启动浪涌；
- 触点温升和寿命；
- 外部保险丝动作；
- 绝缘/耐压方案；
- 断电后安全放电和维修流程。

## 7. 工业环境和故障注入

- 200–600°C多个温点；
- 全功率升温、接近目标降功率、长时间恒温；
- 冷启动、热启动和反复循环；
- 高低环境温度；
- 热电偶开路、反接、松动和外壳接地异常；
- P2开路、短路和低输入阻抗；
- 24V掉电/过冲；
- USB插拔和双电源切换；
- RS-485长线、分支、端接、共模扰动、ESD/EFT和通信中断；
- MCU看门狗复位、DFU和SWD恢复；
- ESD、EFT、传导和辐射干扰；
- 独立超温保护动作。

## 10. 最终放行标准

只有同时满足以下条件，才建议采购和贴装500套：

- 所有P0项目均有实测或设计审查记录；
- 继电器/封装满足最终市电隔离要求；
- P4负载、端子、保险丝、外壳和认证边界明确；
- 独立超温保护已在整机中生效；
- 24V最坏情况不威胁U2输入上限；
- 热电偶在真实机器中的精度和抗干扰达标；
- 0–5V在真实负载下校准合格；
- RS-485拓扑、端接、公共地、共模范围和工业干扰测试合格；
- BOM无未定义或未经验证的替代料；
- 首板、环境、EMC、故障注入和继电器寿命测试通过；
- 量产治具、阈值和追溯记录已确定。
